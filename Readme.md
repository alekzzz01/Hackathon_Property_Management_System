# Hackathon Property Management System

---

## Project Overview

The Hackathon Property Management System is a web application designed to streamline the management of properties, tenants, and rental agreements. This platform provides an efficient way for property managers to handle various tasks, including tenant applications, lease management, and maintenance requests.

## Features

- **Property Management**: Add, edit, and delete property listings.
- **Tenant Applications**: Manage tenant applications and approvals.
- **Lease Management**: Track lease agreements and renewals.
- **Maintenance Requests**: Allow tenants to submit maintenance requests easily.
